# Tic-Tac-Toe
Tic-Tac-Toe created using python
1. Entirely created in python without GUI, can be played on a command line
2. Selecting boxes which already contain an input will skip the turn.
ex - Board:\
| x | o | x |\
|   |   |   |\
|   |   |   |\
say this is the current state of board, if you try to place another "X" on row 1, column 1, you turn will simply get skipped, without any retry.

3. Played against computer
4. Computer AI uses completely random moves, so yeah not very competitive
